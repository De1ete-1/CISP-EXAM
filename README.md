# CISP 考试练习室使用说明

## 打开平台

双击 `index.html`，使用浏览器打开即可。支持离线使用，无需安装，适配电脑和手机。

## 模拟考试

1. 点击“开始模拟考试”，从 522 道题中随机抽取 100 道单选题，同场原题号不重复。
2. 考试时长为 120 分钟，每题 1 分，满分 100 分，70 分及以上通过，未答题计 0 分。
3. 点击选项作答，通过“上一题”“下一题”或答题卡切换题目。
4. 不确定的题目可点击“标记存疑”；需要重选时可点击“清除本题选择”。
5. 勾选“选择答案后自动下一题”，可在作答后自动切换。
6. 完成后点击“提交试卷”，确认交卷；考试到时自动交卷。

快捷键：

- `A`–`D` 或 `1`–`4`：选择对应答案。
- `←` / `→`：切换上一题、下一题。

## 继续考试

作答、题目顺序、存疑标记和考试进度自动保存。刷新或重新打开页面后，点击“继续考试”恢复作答。

离开页面不会暂停倒计时。如果关闭页面后考试到期，下次打开时会自动交卷。

## 成绩与解析

交卷后显示分数、通过结果、用时以及答对、答错和未答题数。

- 切换“错题与未答”“全部”“存疑”，查看对应题目。
- 点击复盘导航中的题号，或使用上一题、下一题逐题查看。
- 每道题均可查看你的答案、题库答案、解析及参考来源；有核对备注的题目会单独显示。
- 点击“导出复盘”，下载包含本场错题和解析的 Markdown 文件。
- 点击“再考一次”，重新随机组卷。

## PDF 原文链接

解析中的 PDF 链接使用相对路径。如需点击链接查看原文，将以下两个 PDF 放在 `index.html` 同一目录，并保持文件名一致：

```text
项目目录/
├── index.html
├── 题库1-522题.pdf
└── 注册信息安全专业人员培训教材7.13.pdf
```

点击解析中的来源链接，即可打开对应 PDF 并尝试跳转到引用页。若浏览器不支持页码跳转，可按链接显示的页码手动查阅。

移动项目时保持上述相对位置即可，无需修改本机路径。未放置 PDF 时，仍可正常考试和查看内嵌题目、插图及解析。

## 错题本

考试中的错题和未答题会自动加入错题本。

1. 打开“错题本”，选择一道题进行自测。
2. 点击“查看答案与解析”，核对答案并学习解析。
3. 理解后点击“标记已掌握”，将题目移出待巩固列表。
4. 切换到“全部错题”可查看已掌握题目，并按需“移回待巩固”。

## 题库浏览

打开“题库浏览”，可按题号范围筛选，或搜索原题号、关键词。

选择题目后可先自行作答，再点击“查看答案与解析”；点击“重新自测”可隐藏答案重新练习。

## 学习总览与考试记录

- “学习总览”展示已练题数、待巩固错题、模拟考均分和题库学习进度。
- “考试记录”保留最近 30 场已提交考试，可查看成绩、用时，并返回当次试卷复盘。

## 保存学习记录

学习记录保存在当前浏览器中，建议固定使用同一浏览器、从同一路径打开页面。清理浏览器数据或使用隐私模式可能导致记录丢失。

## 重新导入题库（可选）

导入脚本通过 `--source` 指定题库 PDF，不在源码中保存本机文件位置。以 PDF 位于项目目录为例，在项目目录执行：

```sh
python3 tools/import_questions.py --source './题库1-522题.pdf'
python3 tools/build.py
```

第一步更新结构化题库，第二步将题库重新打包到 `index.html`。如果 PDF 位于其他位置，将 `--source` 后的参数替换为实际文件路径。

导入适用于本项目原有的 522 题 PDF 格式，需要 Python 及 `pypdf`、`pdfplumber`、`pypdfium2`、`Pillow` 依赖。日常打开 HTML 练习无需执行这些命令或安装依赖。
